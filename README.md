# Stroke Prediction System Using Machine Learning

## Project Overview
A machine learning-based system designed to predict stroke risk using structured healthcare datasets and patient health indicators.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Jupyter Notebook

## Project Features
- Healthcare data preprocessing
- Exploratory data analysis
- Missing value handling
- Feature encoding
- Machine learning classification
- Model performance evaluation

## Project Structure
- `Stroke_Prediction.ipynb` – Machine learning implementation.
- `healthcare-dataset-stroke-data.csv` – Healthcare dataset.

## How to Run
1. Download or clone the repository.
2. Open the notebook in Google Colab or Jupyter Notebook.
3. Upload the healthcare dataset.
4. Execute all cells sequentially.
